## 争点

树的形状与所有权细节是否按现行实现定死，还是另立一套节点模型。

## 判据（逐条）

| # | 判据 | 来源 |
| --- | --- | --- |
| 1 | 树是唯一公开模型，不引入 DOM 包装 | R-D-01 |
| 2 | 异构值有 tag 判别 | R-D-02 |
| 3 | 所有权与释放规则唯一、可验证 | R-D-03 |

## 判决（upheld）

采用现行实现，不再另立形状：

- `JsonVal` 为具名 `union JsonValue` + `int tag`；标量不额外堆分配。
- 对象 `JsonObj` = 保序 `Str` 键数组 + `JsonRef` 值数组 + `Map<Str,int>` 查找索引；键插入时深拷贝，覆盖保首位、last-wins。
- 数组 `JsonArr` = `JsonRef` 元素数组。
- 节点 `JsonNode` 带 `refs` 引用计数；`json_retain` / `json_release` 公开；容器 Drop 显式循环释放 `[0,len)` 后再释放数组/键。
- 环允许存在于内存，编码期报 `JSON_ERR_CYCLE`。

## 生效范围

R-D-01/02/03 的验收以现实现为准；`docs/adr/0001…0006` 继续有效，不新增第二套节点形状。

## 理由

实现、ADR 与用例已经一致；另立模型只会制造迁移成本。剩余空白（例如 Map 键冗余副本）是性能优化，不改变形状。

## 失效条件

出现无法在现形状上表达的公开承诺（例如需要原地 DOM 包装）时重开。
